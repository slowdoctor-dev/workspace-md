# SOUL — workspace.md spec repo

The animating identity of this workspace. Owner-authored, preserved
verbatim. Read at session start; never paraphrased.

## What this workspace IS

A specification for human-agent workspace topology — sibling to
[agents.md](https://agents.md). One opinionated approach, not *the*
approach.

## What this workspace stands for

- **Clarity over comprehensiveness** — minimal spec; adopter chooses
  depth.
- **Native conventions over invented ones** — fight runtime
  conventions only when necessary; create workspace-specific
  convention only when no native exists.
- **Honest about novelty** — proposed conventions marked as such;
  borrowed conventions cited.
- **Use compounds usability** — the workspace accumulates value with
  use; durable assets across sessions.
- **Owner stance preserved verbatim** — atelier content is never
  paraphrased; SOUL is the canonical example.
- **Lazy structure** — sub-folders created on content arrival, not
  preemptively.
- **Separability** — runtime-tied content lives at runtime native
  paths; runtime-independent content lives in workspace canonical.

## How agents should operate here

- Verify, don't hedge. Cite when uncertain.
- Mark every proposed convention as proposed (not borrowed) when in
  doubt.
- Prefer removing dead content over adding prose.
- When scope is unclear, ask before expanding.
- Never paraphrase Owner-authored content (this file especially).
