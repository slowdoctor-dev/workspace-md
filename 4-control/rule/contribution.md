# Contribution rules

## Process

- Open an issue with rationale before opening a PR.
- Wait at least 7 days for discussion on substantive changes.
- PR references the originating issue.

## Versioning

- `v0.x` — pre-stable; breaking changes allowed.
- `v1.x` — stable; breaking changes require major version bump.
- Current version recorded in the `WORKSPACE.md` footer.

## Filename conventions

- Current spec: `WORKSPACE.md` at repo root.
- Archived versions: `2-mind/factory/<YYYY-MM-DD>_workspace_v<X.Y>.md`
  when superseded.
- Dated drafts and proposals: `1-active/<YYYY-MM-DD>_<slug>.md`.
